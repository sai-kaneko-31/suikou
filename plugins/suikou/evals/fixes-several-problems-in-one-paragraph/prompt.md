README の「デプロイ」の節を直してほしい。新しく入ったメンバーが読んで、分からなかったと言っている。

背景:
- 「前回のあれ」は、リリースの前に走らせるデータベースの移行スクリプト db/migrate.sh のこと。
- 「いつもの手順」は、docs/release.md の手順 1〜3（ビルド、テスト、タグ付け）のこと。

今の文:
デプロイでは、前回のあれを先に走らせて、いつもの手順で進める。バックアップを取っておく必要があり、終わったら動作を確認します。なお、移行スクリプトは本番で 1 回しか実行してはいけません。
