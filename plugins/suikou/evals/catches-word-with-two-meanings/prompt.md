チームの README の一節を直してほしい。「読みづらい」と言われたが、どこがか分からない。

サービスの背景: 組織の管理者が、設定画面でメールアドレスを入力して、他の人を組織に招待する。招待された人は、届いたメールのリンクから組織に参加する。参加すると、招待した管理者に通知が届く。

今の文:
ユーザーは、設定画面でメールアドレスを入力して、ユーザーを招待できる。ユーザーは、届いたメールのリンクを開くと、組織に参加できる。ユーザーが参加すると、ユーザーに通知が届く。
