レシピ検索アプリの説明文を直してほしい。「読みづらい」と言われた。

材料を選ぶと「作れる料理を見る」ボタンが押せるようになる。ボタンを押すと、選んだ材料だけで作れるレシピが一覧で出る。一覧のレシピを開いて人数を変えても、検索の条件は選んだ材料のままで変わらない。選んだ材料だけで作れるレシピがないときは、一覧が空になる。

今の文:
選んだ材料の一覧を見ているよ。人数を変えても、検索の条件はこの材料のままだよ。一覧が空のときは、選んだ材料だけで作れるレシピが無いよ
